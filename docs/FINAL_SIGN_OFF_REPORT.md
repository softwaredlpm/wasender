## Executive Summary

The on-premise Windows desktop utility `WASENDER` (WhatsApp & BUSY Accounting automation) has been transformed into a cloud-native, multi-tenant enterprise SaaS architecture capable of serving **100+ concurrent customer organizations** with zero cross-tenant data leakage.

### Core Architectural Invariant (Maintained 100%)
- **Direct BUSY Database Access** (`busy_service.js`, `busy_db_bridge.ps1`, MS Access BDS / MS SQL) and **`whatsapp-web.js` browser sessions** remain **100% local on customer Windows PCs**. They **never run on Vercel or cloud VPS**.
- **Ephemeral Invoice PDF Purge**: Temporary invoice PDFs generated by local accounting software are transmitted to WhatsApp and **immediately purged from local disk** via `fs.unlinkSync`. Invoices are **never permanently stored in cloud storage**.

## Production Deployment Runbook

### 1. Cloud VPS API Server Deployment (Ubuntu / Debian VPS)

#### Option A: Docker Compose (Recommended)
```bash
# 1. Clone repository and navigate to root
cd /opt/wasender

# 2. Populate production environment
cp .env.example .env
nano .env

# 3. Verify environment pre-flight
node scripts/verify-production-env.js

# 4. Launch containers
docker-compose up -d --build

# 5. Verify container health
docker-compose ps
curl http://localhost:5001/health
```

#### Option B: Native PM2 Cluster
```bash
cd /opt/wasender/server
npm ci --omit=dev
pm2 start ecosystem.config.js --env production
pm2 save
pm2 startup
```

### 2. Frontend Deployment (Vercel)
```bash
# Deploy to Vercel with zero build configuration
cd /opt/wasender
vercel --prod
```

### 3. Customer Windows Agent Installation
1. Provide the customer with `WASENDER-Agent.exe` (from `agent/dist/WASENDER-Agent.exe`).
2. Run `scripts\install-service.bat` as Administrator to install the agent as a persistent Windows Task Scheduler background task.
3. The customer pairs their device once using:
   ```cmd
   WASENDER-Agent.exe --pair WAS-A1B2C3D4
   ```
4. The agent immediately connects to the Cloud VPS WebSocket Hub, establishes the local BUSY bridge, and is ready for real-time invoice automation and WhatsApp dispatch.
